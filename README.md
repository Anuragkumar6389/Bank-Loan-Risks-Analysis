# Bank Loan Approval & Risk Analysis Dashboard 🏦

A interactive **Streamlit** web application for bank loan approval prediction and risk analysis powered by Machine Learning algorithms.

## 📌 Features
- **Loan Approval Prediction**: Real-time evaluation of loan application details.
- **Interactive UI**: Built using Streamlit and Plotly for visual breakdown and metrics.
- **Machine Learning Integration**: Uses Scikit-learn models to predict approval probabilities and assess risk factors.

## 🛠️ Tech Stack
- **Python** (3.x)
- **Streamlit** (Web Interface)
- **Plotly** (Data Visualization)
- **Scikit-learn** (Machine Learning Pipeline)
- **Pandas & NumPy** (Data Processing)
